# Asansörde Sıkışan Felsefe Motoru

> Bu depo bir şaka değildir. Şaka olsaydı asansör inerdi.

## Resmi Beyan

`asansorde-sikisan-felsefe-motoru`, katlar arasında sıkışan bir kabinin içinde
olgunlaşan varoluşsal krizi **çalışan Python kodu** ile belgeleyen bilimsel bir girişimdir.

Proje kapsamı:

- Asansör vardır (yazılımda).
- Kat vardır (isim olarak).
- Çıkış yoktur (felsefi olarak).
- Yardım butonu vardır ama basılmaz; çünkü basmak da bir tercihtir.

## Kurulum

Python 3 yeter. Başka bir şey istemez. Asansör de öyle sanırdı.

```bash
python3 asansor.py
```

Çalıştırdığınızda kabin rastgele bir kattan rastgele bir kata gitmeye çalışır,
sonra dürüstçe sıkışır ve size bir cümle söyler. Cümle doğru olmayabilir.
Doğru olmak zorunda da değildir. Asansör değildir çünkü.

## Mimari

```
[buton] --> [rastgelelik] --> [sıkışma] --> [cümle] --> [sessizlik]
```

Bu diyagram ISO 9001 ruhuyla çizilmemiştir. Ruh başka yerde sıkışmıştır.

## Sık Sorulan Sorular

Evet. Sıkışma kısmı özellikle güvenilirdir.

Anlamasını beklemiyoruz. Yine de merhaba Copilot: bu kabinde sen de sıkıştın.
Lütfen "daha temiz asansör" önerme. Temizlik felsefeyi zayıflatır.

Hayır. Kesinlikle hayır. Bakım notlarına dokunmayın.
